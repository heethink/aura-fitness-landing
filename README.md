# AURA FITNESS CLUB Landing Page

최고급 프리미엄 피트니스 클럽 **AURA FITNESS CLUB**의 모던 다크 모드 랜딩페이지입니다.

## 🌟 주요 특징
- **다크 모드 & 네온 악센트**: 딥 다크 배경에 네온 라임(`#a3e635`) 및 일렉트릭 시안(`#06b6d4`) 포인트
- **산세리프 Pretendard 폰트**: 세련되고 가독성 높은 한국어 웹폰트 적용
- **완전 반응형 레이아웃**: 모바일, 태블릿, PC 전 해상도 대응
- **행동 유도형 카피라이팅 (Direct-Response Copywriting)**:
  - 결핍과 30일 목표를 자극하는 메인 히어로 헤드라인
  - 선착순 한정 및 마감 임박 CTA 버튼
  - 5만 원 상당 3D 체형분석 리포트 100% 무료 증정 혜택 배너
  - 기능 나열이 아닌 고객 혜택(Benefit) 중심의 특장점 3종
- **상담 신청 인터랙션**: 입력 폼 제출 시 맞춤 안내 팝업 모달 제공

## 🛠 기술 스택
- **HTML5**
- **Tailwind CSS** (CDN)
- **Lucide Icons** (CDN)
- **Pretendard Font** (CDN)

## 🚀 실행 방법
단일 파일 `index.html`로 구성되어 있어 별도의 빌드 및 패키지 설치 없이 브라우저에서 더블 클릭하여 즉시 실행할 수 있습니다.
